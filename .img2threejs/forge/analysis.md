# Reference intake and direct-authoring continuation

The source is a 640 × 960 isolated generated concept of an industrial furnace,
with a cylindrical pressure shell, octagonal base, six splayed supporting legs,
a suspended pouring crucible, four crown supports and an overhead circular rail.
The main shell occupies roughly two thirds of the assembled height. The front
molten inspection slot is vertical and framed, with a separate lower outlet.
Visible white ceramic panels contrast with dark oxidized metal. Bronze pipe
elbows, circumferential clamps, bolts, narrow ladders and grated service decks
supply smaller scale detail. Back surfaces, joints inside the shell and exact
physical dimensions are not visible; their reconstruction is inferred.

Conditional suitability: the isolated silhouette is clear enough for a stylized
real-time reconstruction. Exact photoreal likeness is not established by this
single source. The original WebP is valid but the upstream admission script only
decodes PNG in this Linux environment. A lossless PNG conversion is admitted;
the WebP source is retained unchanged.

Existing source already contains a direct Three.js model with no legacy state
or per-pass reviews. This pipeline records that baseline instead of pretending
that it was produced by newly passing sequential generator gates. The direct
route follows the skill's unsupported-route continuation policy: retain the
new state checklist, specification, source geometry export, Blender inspection,
WebGL multi-angle capture, deterministic diagnostics and explicit review gaps.
The upstream generator is not used to overwrite the existing playable model.

Changed method: preserve working runtime hierarchy and add instanced band
fasteners (48), service ladder (14 instances), and open molten reservoir. Export
that exact runtime geometry into Blender 4.5.3 LTS, inspect the actual triangles
and emit editable blend + portable GLB. No external model, billboard or reference
pixels replace the model. The GLB is an inspection artifact, not a second runtime
implementation; src/arena-assets.js remains the shipping geometry authority.

Quality contract: preserve source silhouette and action nodes, no topology,
collision, operator or weapon changes; three orbit renders; all textures have
independent color/roughness/normal signals; no transmission pass; existing arena
ceilings remain unchanged. Exact-match acceptance requires the existing strict
quality thresholds; incomplete gates stay incomplete. Geometry correctness and
fidelity are separate conclusions.
